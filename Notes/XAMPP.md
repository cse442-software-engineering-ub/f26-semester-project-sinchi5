# XAMPP Resources

## 1 - XAMPP Official Website Overview and Download

**Link:** https://www.apachefriends.org

This is the official website for XAMPP and it has a general intro to what it is and what it includes. Its a free, open source local web server environment which packages Apache, MariaDB, PHP, and Perl together. It allows devs to run and test websites directly on their computers instead of needing to upload them to a live web server.

---

## 2 - XAMPP Wikipedia Page

**Link:** https://en.wikipedia.org/wiki/XAMPP

Further explanation of what XAMPP is, what its used for, its features, etc. XAMPP used to use MySQL, but switched to MariaDB in 2015. It only requires one zip, tar, 7z, or exe file to be downloaded and run, with little to no configuration required. Windows version requires Microsoft Visual C++ 2017 Redistributable. It's primary use is a development tool to allow web devs to test their work on their own computers without any access to the internet.

## 5 - XAMPP GeeksForGeeks

**Link:** https://www.geeksforgeeks.org/php/xampp-full-form/

An explanation of what each part of XAMPP is and what it's used for. X stands for cross platform, ex Windows, Linux, and mac. A is for Apache, which handles requests and delivering web content from the local server to the developer's browser. MariaDB (M) is a fork of the MySQL database management system, its an open-source database manager. PHP (P) is a server-side scripting language used for web dev. Perl (P) is a high-levl, general purpose interpreted programming language for web dev, text processing, and system administration tasks.
