# Noters — wireframe

A single-file HTML/CSS/JS wireframe exploring the desktop and mobile layout
for Noters: an overview dashboard, notes list, note detail with
collaborator invites, and a course schedule view.

## Run it

No install, no server needed — just open `index.html` directly in a
browser (double-click it, or drag it into a browser window).

## What's implemented

- Overview: upcoming schedule strip + pinned notes
- Notes: filterable list by category (School / Work / Personal)
- Note detail: collaborators list and an invite dialog
- Schedule: upcoming assignments/exams
- Responsive layout — resize below ~780px to see the mobile bottom-nav version

## Notes

This is a wireframe for visual/layout exploration, not a functional
prototype — clicking around updates the UI but nothing persists or
calls a real backend. Font is Inter, per the team's design agreement.
